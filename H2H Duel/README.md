In order to maintain the ``scr-server`` controlled racing against other (at least equally competitive), overwrite the given ``quickrace.xml`` with the setup file in your TORCS directory:

``\torcs\config\raceman``

THere is predefined model ``inferno``, which is the default open-wheeler type of bot in TORCS. According to the results and sources, it is capable of doing below ``1:20`` on Laguna Seca.
